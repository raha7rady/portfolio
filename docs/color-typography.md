# Color & Typography — تصمیمات نهایی طراحی

هدف: هویت بصری متمایز، نه رنگ‌های پیش‌فرض Tailwind/Bootstrap. پالت برای یک برند Backend-محور، جدی ولی مدرن انتخاب شده (نه شرکتی و خشک، نه بیش‌ازحد رنگارنگ).

---

## ۲. تایپوگرافی

| نقش | فونت | توضیح |
|---|---|---|
| متن فارسی (UI + بدنه) | **Vazirmatn** | خوانایی بالا، وزن‌های متنوع، مناسب UI مدرن |
| متن انگلیسی (UI + بدنه) | **Inter** | استاندارد صنعت برای رابط‌های مدرن، خوانایی عالی در سایزهای کوچک |
| کد و بلوک‌های Code (بلاگ) | **JetBrains Mono** | طراحی‌شده مخصوص کد، تفکیک واضح کاراکترهای شبیه به هم (0/O، 1/l) |

### وزن‌های فونت (Font Weights) مورد استفاده
- عنوان‌های بزرگ (Hero, H1): `700` (Bold)
- عنوان‌های میانی (H2, H3): `600` (SemiBold)
- بدنه متن: `400` (Regular)
- متن کم‌رنگ/توضیحات: `400` با رنگ Muted، نه وزن سبک‌تر (برای حفظ خوانایی فارسی)

### مقیاس اندازه (Type Scale — پایه ۱۶px)
| عنصر | اندازه (rem) |
|---|---|
| Hero Title | 3rem (48px) |
| H1 صفحات داخلی | 2.25rem (36px) |
| H2 | 1.5rem (24px) |
| H3 | 1.25rem (20px) |
| Body | 1rem (16px) |
| Small/Caption | 0.875rem (14px) |

## ۳. فاصله‌گذاری و Radius (برای یکدستی کامپوننت‌ها)

- Border Radius استاندارد کارت‌ها و دکمه‌ها: `0.75rem (12px)`
- فاصله داخلی استاندارد کارت‌ها (Padding): `1.5rem (24px)`
- فاصله بین Sectionهای اصلی صفحه: `5rem (80px)` در Desktop، `3rem (48px)` در Mobile

---

## ۴. نحوه پیاده‌سازی در فاز ۲ (Tailwind CSS Variables)

این مقادیر مستقیماً در `tailwind.config.ts` به‌صورت رنگ‌های سفارشی (`primary`, `accent`, `surface`, ...) تعریف می‌شوند و فونت‌ها از طریق `next/font` (برای Inter) و `@font-face` محلی (برای Vazirmatn) بارگذاری می‌شوند — جزئیات دقیق کد در فاز ۲ ارائه می‌شود.
